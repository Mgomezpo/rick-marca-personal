# Framework: Desglose Paso a Paso (High-Retention Method)

---
**Rama:** `02_autoridad_y_sistemas`  
**Objetivo Psicológico:** Maximizar la tasa de guardados (Saves > 6%) y compartidos (Shares > 3%) mediante un marco educativo hiperestructurado. El espectador reconoce una densidad de valor tan alta que siente la obligación de atesorar la pieza como material de referencia para su propio trabajo.  
**Duración Objetivo:** 50 a 60 segundos (~120-140 palabras).  
---

## 1. La Curva de Retención Segundo a Segundo

```
[00:00 - 00:05] EL SISTEMA EN 3 PASOS   ──► Promesa de marco cerrado y concreto.
[00:05 - 00:18] PASO 1: EL CIMIENTO      ──► La base que casi todos se saltan.
[00:18 - 00:32] PASO 2: EL MOTOR         ──► La palanca de ejecución o automatización.
[00:32 - 00:46] PASO 3: EL CIERRE        ──► La auditoría o control de calidad final.
[00:46 - 00:55] CIERRE DE ATESORAMIENTO  ──► Justificación de guardado para aplicación futura.
```

---

## 2. Matriz de Guionización (Doble Codificación Obligatoria)

| Bloque Temporal | Función Psicológica | Canal Auditivo (Teleprompter - Voz del Creador) | Apoyo Visual / Pantalla |
| :--- | :--- | :--- | :--- |
| **00:00 - 00:05** | **El Sistema Cerrado** | *"[Frase de apertura: 'Si quieres lograr X sin cometer Y, este es el protocolo exacto de 3 pasos que usamos']."* | **[TEXTO GRANDE: 'EL PROTOCOLO DE 3 PASOS PARA [OUTCOME]']**.<br>Creador a cámara con gráfica de los 3 pasos. |
| **00:05 - 00:18** | **Paso 1: El Cimiento** | *"[Paso 1: Definir la variable base o la regla innegociable antes de tocar cualquier herramienta]."* | Badge: **01 / 03**. Pantalla con el checklist o documento base. |
| **00:18 - 00:32** | **Paso 2: El Motor** | *"[Paso 2: El mecanismo de ejecución que hace el trabajo pesado y elimina la fricción manual]."* | Badge: **02 / 03**. Visual de la herramienta en uso o el código ejecutándose. |
| **00:32 - 00:46** | **Paso 3: El Cierre** | *"[Paso 3: El filtro de control que garantiza que el resultado no tenga fallas antes de salir al público]."* | Badge: **03 / 03**. Visual de la compuerta de validación o métrica de salida. |
| **00:46 - 00:55** | **Atesoramiento** | *"Guarda este video para cuando vayas a implementar [PROCESO] esta semana, o compártelo con tu equipo técnico."* | Creador a cámara, gesto sobrio y cierre directo. |

---

## 3. Leyes de Reducción
1. Exactamente 3 pasos (máximo 4). Si hay más pasos, se divide la pieza en una serie o carrusel.
2. Cada paso debe contener un verbo de acción y un entregable tangible.
